# Kim-Store
Kim的图书、影视库

## 当前版本

这是一个移动端优先的本地版 Web/PWA，可直接打开 `index.html` 体验，也可通过静态服务预览。

已包含：

- 首页自定义栏目
- 图书/影视大类切换
- 封面卡片资料库列表
- 本地搜索、状态筛选、排序
- 搜索候选后保存作品
- 条目详情弹窗与状态、进度、版本、评分、总评编辑
- 多次完成记录管理
- 影视主题曲/插曲补充记录
- 多选后批量改状态、添加标签、移除标签
- 固定标签与自定义标签管理
- JSON 导出备份与 JSON/CSV 导入
- PWA manifest 与离线缓存

当前版本使用浏览器 `localStorage` 保存数据，不接入真实作品 API。搜索页使用内置候选数据模拟自动补全流程，后续可替换为 Google Books、TMDB 等真实数据源适配器。

## 本地预览

```bash
perl serve.pl
```

默认端口是 `8000`。如需换端口：

```bash
KIM_STORE_PORT=8080 perl serve.pl
```
